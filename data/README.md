# CIC-IDS2017 Dataset: Canadian Institute for Cybersecurity

This directory stores authentic network flow datasets from the **Canadian Institute for Cybersecurity (CIC)** at the **University of New Brunswick (UNB)**.

## Canonical Dataset Files Used
1. `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv`
   - Real attack labels: `BENIGN`, `Web Attack – Brute Force`, `Web Attack – XSS`, `Web Attack – Sql Injection`
   - Connection to Digital Signature Security:
     - **Web Attack – Brute Force**: Represents credential theft & brute-forcing against digital signing authorization endpoints (**Impersonation Threat**).
     - **Web Attack – Sql Injection**: Represents database exploitation to manipulate public key trust stores or extract private key metadata (**Forgery & Integrity Threat**).
     - **Web Attack – XSS**: Represents session hijacking of authorized document signers to trigger unauthorized signing operations (**Unauthorized Verification/Signing Threat**).
2. `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv`
   - Real attack labels: `BENIGN`, `PortScan`
   - Represents reconnaissance and scanning against PKI infrastructure, OCSP responders, and Certificate Authority services.

## Acquisition
The dataset is downloaded directly from official/canonical mirrors using `python data/download_dataset.py`.

## Data Characteristics
- Features: 78 network flow statistics generated by CICFlowMeter (flow duration, packet lengths, inter-arrival times, TCP flags, header lengths, sub-flow statistics).
- Authenticity: Raw CSV data generated from real traffic captures containing both genuine benign traffic and orchestrated cyber attacks.
