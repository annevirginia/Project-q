How Risk Scores Work

QuantumShield uses a weighted factor model to compute risk scores. Each factor is independently normalized to 0–100 and contributes to the final score based on its weight:

FactorWeightWhat It Measures
Algorithm Risk25%Vulnerability of the cryptographic algorithm to quantum attack (Shor/Grover)
Data Sensitivity20%Classification level (Public → Highly Restricted)
Data Lifetime15%How long data must remain confidential
Asset Criticality15%Business impact if compromised
Internet Exposure10%External attack surface accessibility
Migration Complexity10%Difficulty of transitioning to PQC
Inventory Uncertainty5%Confidence in the asset's classification

Security Limitations

This project is an educational simulation and risk-management demonstrator. It:

  • Does not guarantee security
  • Does not predict the exact arrival of CRQCs
  • Is not a substitute for professional security assessment
  • Uses only synthetic data — no real credentials, keys, or certificates
  • Runs locally with no external network scanning
  • All remediation is simulated and dry-run only

Recommendation: Get expert review before any production use of these concepts.
